# 🎯 Number Guessing Game

A simple Python-based number guessing game where the computer randomly
selects a number between 1 and 100 and the player tries to guess it.

## 🚀 Features

- Random number generation
- User input handling
- Higher/Lower hints
- Attempts counter
- Interactive command-line gameplay

## 🛠️ Technologies Used

- Python
- Random module

## ▶️ How to Run

```bash
python number_guessing_game.py
