# 🐍 Snake Water Gun Game

A simple command-line Snake Water Gun game built using Python.

This project is a beginner-friendly Python project that demonstrates user input, dictionaries, conditional statements, input validation, and random selection.

---

## 🎮 Game Rules

The game follows these rules:

- 🐍 Snake beats 💧 Water
- 💧 Water beats 🔫 Gun
- 🔫 Gun beats 🐍 Snake
- Same choice = Tie

### Game Logic

| Your Choice | Computer Choice | Result |
|------------|-----------------|--------|
| Snake 🐍 | Water 💧 | You Win |
| Water 💧 | Gun 🔫 | You Win |
| Gun 🔫 | Snake 🐍 | You Win |
| Same | Same | Tie |
| Otherwise | Otherwise | You Lose |

---

## ✨ Features

- 🎲 Random computer choice
- 🐍 Snake, Water and Gun options
- ✅ Input validation
- 🔤 Case-insensitive input
- 🧹 Handles extra spaces in input
- 🗂️ Dictionary-based game logic
- 🤝 Tie detection
- 🎉 Win/Lose detection
- 💻 Command-line interface
